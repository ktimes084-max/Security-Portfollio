This portfolio highlights two core cybersecurity projects focused on threat detection and application security. 

Project 1 details a container vulnerability assessment of a Dockerized application using Trivy, identifying critical flaws like authentication bypasses and hardcoded secrets. Together, these projects demonstrate practical expertise in security research, automated vulnerability scanning, and actionable remediation planning.

Project 2 provides a comprehensive analysis of signature-based, behavior-based, and hybrid malware detection techniques, evaluating their accuracy and resource efficiency.
